# Tool Factory 1 — Launch Packs

Internal operating doc for launching the eight free NoteDrift tools. One self-contained pack per tool: positioning, SEO hooks, cross-sell, and ready-to-adapt copy for email, social, video, and OG.

**How to use this**
- Copy the field you need, tighten for the channel, ship. Nothing here is precious — it's a starting line, not a script.
- **Search volumes:** none are invented. Any SEO hook is a phrase to *validate* — pull real numbers from **Search Console** before you prioritize.
- **Email:** every newsletter here goes to the **opted-in list only**. Never auto-add a tool user to marketing email. If we want tool → email later, it's an explicit opt-in on the page, not a silent capture.
- **Voice check:** useful, smart, energetic, clean, confident, a little playful. Never "revolutionary," never fake urgency, never a dark pattern. The tools are genuinely free and no-signup — say so plainly and let that do the work.

## Rollout notes (not per-tool)

- **Sequencing:** Lead with the tools that have the cleanest hand-offs and highest intent — **Merge PDF**, **Signature Maker**, and **QR Code Generator** — because each has a strong, honest "here's the catch other tools have, and we don't" angle plus a natural next step in the ecosystem.
- **The through-line to reuse everywhere:** *free, no signup, runs in your browser.* It's true, it's differentiated, and it never gets old. Say it plainly instead of dressing it up.
- **Cross-sell is the strategy, not a footnote.** Every pack ends by handing the user to the next tool or into the NoteDrift editor. That chain — free tool → free tool → editor → Pro (ad-free, unlimited cloud, cross-device, pro exports, $3.99/mo or $29.99/yr) — is the whole point. Keep the hand-offs specific and useful, never bait.
- **Before you prioritize any SEO hook:** confirm it in **Search Console**. Every phrase above is a hypothesis until the data says otherwise.
- **Email discipline:** these newsletters ship to the opted-in list only. If a tool page ever collects email, it's an explicit, clearly-labeled opt-in — no pre-checked boxes, no silent capture.
